# snake-loop-competition

零后端纯前端静态应用，由 Vite 构建。发布根 `/` 呈现「Web版多用户同屏贪吃蛇大战」，
三消小游戏保留于非根路径 `/three-match/`。

## 多人同屏贪吃蛇大战

双人同屏贪吃蛇直接以发布链接根路径 `/` 打开即可游玩。

- 玩家 1 使用方向键，玩家 2 使用 WASD
- 桌面与移动端均提供双玩家屏幕方向按钮
- 吃到能量点后对应玩家得分并增长，碰撞结束比赛
- 撞墙、自撞和两条蛇相撞都会进入结束面板
- 支持暂停、重新开始和本地最高分持久化
- 对战结束的结算面板展示「本局排名」：按本局得分降序排列，同分并列显示名次
- 结算面板提供「再来一局」按钮，一键复位双方分数、等级与排行并直接开始新一局

源码位于 `src/game/`，发布根 HTML 为 `index.html`。

## 玩法

用方向键 / WASD 控制蛇移动，吃食物得分，撞墙或撞自己结束。

- 空格暂停，R 重新开始
- 每吃 5 个食物升一级，蛇速加快，分数递增
- 最高分本地持久化（localStorage）

## 开发

```bash
npm install
npm run dev        # 本地开发
npm run build      # 生产构建到 dist/
npm run preview    # 预览构建产物（0.0.0.0:4173）
```

多页面构建产物：`dist/index.html`（贪吃蛇发布入口）、
`dist/three-match/index.html`（三消兼容页面）与 `dist/legacy-snake/index.html`（历史贪吃蛇页面）。

发布入口说明：在线发布链接根路径 `/` 直接呈现「Web版多用户同屏贪吃蛇大战」。

## 食物投放规则

食物只在空格中投放，永不落在双方蛇身或蛇头当前格上；棋盘无空格时返回 `{-1,-1}` 哨兵。
投放实现先收集全部空格再随机取一个，空格越少时抽取仍是常数开销。
